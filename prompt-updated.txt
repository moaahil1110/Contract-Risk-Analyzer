=== PROJECT STATUS ===
Build a Contract Risk Analyser web app for Aahil (BTech CSE, 
PES University) as a portfolio project for placements. The app 
allows users to upload contract PDFs, extracts and segments 
clauses, compares each clause against legal benchmarks using RAG, 
scores risk (high/medium/low), explains risks in plain English, 
suggests safer alternatives, and generates an overall Contract 
Health Score (0-100).

TECH STACK (strictly follow, no substitutions):
- Backend: FastAPI (Python 3.11)
- PDF parsing: PyMuPDF (fitz) + Tesseract OCR fallback
- Clause splitting: Regex first, Qwen3.5 fallback
- Embeddings: sentence-transformers (all-MiniLM-L6-v2)
- Vector DB: ChromaDB (local, persisted to ./chroma_db)
- LLM primary: Qwen3.5:9b via Ollama (local, http://localhost:11434)
- LLM fallback 1: Gemini 2.0 Flash (via google-generativeai)
- LLM fallback 2: Claude claude-sonnet-4-6 (via anthropic SDK)
- Database: Supabase (PostgreSQL)
- Auth: Supabase Auth (JWT middleware)
- PDF export: WeasyPrint
- Frontend: React + Vite + TailwindCSS + shadcn/ui
- Deployment: Railway (backend) + Vercel (frontend)
